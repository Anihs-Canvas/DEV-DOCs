═══════════════════════════════════════════════════════════════════════════════
  SESSION 2: Generate Django Backend
═══════════════════════════════════════════════════════════════════════════════

Duration: ~1-2 hours with Claude
Output:   Django project with models, serializers, API, and import command

PROMPT FOR CLAUDE:

---
I have a course-data.json file (attached) that contains structured content for
a Kubernetes certification study guide. I need you to build a Django LMS backend.

PHASE A — DATA MODELS (apps/courses/models.py, apps/quizzes/models.py, etc.)

Create these Django models that map 1:1 to the JSON structure:

  Course
    - slug, title, description, version, total_hours, is_published

  Part
    - course (FK), number, title, level, cka_domains (JSONField),
      cka_weight (int), order

  Chapter
    - part (FK), number, title, duration, level,
      learning_objectives (JSONField), order

  Section
    - chapter (FK), section_id, title, section_type,
      content_html (TextField), content_json (JSONField), order

  ContentComponent
    - section (FK), component_type, variant, title,
      body_html, code, language, filename, metadata (JSONField), order

  Quiz
    - chapter (OneToOneField), shuffle, passing_score

  Question
    - quiz (FK), text, explanation, domain, difficulty, order

  AnswerOption
    - question (FK), text, is_correct, order

  FlashcardDeck
    - course (FK), name, slug

  Flashcard
    - deck (FK), chapter (FK nullable), front, back, order

  FlashcardReview
    - user (FK), flashcard (FK), ease_factor, interval_days,
      repetitions, next_review_at, last_review_at, last_quality

  UserProgress
    - user (FK), section (FK), completed, completed_at,
      time_spent_seconds   [unique_together: user, section]

  QuizAttempt
    - user (FK), quiz (FK), score, total, passed,
      answers (JSONField), attempted_at

  UserCourseEnrollment
    - user (FK), course (FK), enrolled_at, completed_at,
      last_accessed_at, last_section (FK nullable)
      [unique_together: user, course]

PHASE B — MANAGEMENT COMMAND (courses/management/commands/import_course_data.py)

Write a Django management command that:
  python manage.py import_course_data course-data.json

The command must:
  1. Read the JSON file
  2. Create Course, Parts, Chapters, Sections, ContentComponents
  3. Create Quizzes, Questions, AnswerOptions
  4. Create FlashcardDecks, Flashcards
  5. Use update_or_create() on slug/id fields (idempotent — safe to re-run)
  6. Print progress: "Importing Part 1/11... ✓ 4 chapters, 45 sections"
  7. Validate data integrity before committing
  8. Use a transaction — rollback on any error

PHASE C — DRF SERIALIZERS + API ENDPOINTS

Create REST API endpoints:

  GET    /api/courses/{slug}/              ← Course detail
  GET    /api/courses/{slug}/parts/        ← Parts with nested chapters (shallow)
  GET    /api/courses/{slug}/chapters/{id}/ ← Chapter with sections + components
  GET    /api/courses/{slug}/sections/{id}/ ← Single section

  GET    /api/progress/{course_slug}/       ← User's progress summary
  POST   /api/progress/sections/{id}/complete/
  GET    /api/progress/resume/              ← Last accessed section

  GET    /api/quizzes/{chapter_id}/         ← Quiz questions (no correct answers in response!)
  POST   /api/quizzes/{quiz_id}/submit/     ← {answers: {q1: "b", q2: "a"}} → score

  GET    /api/flashcards/decks/
  GET    /api/flashcards/decks/{id}/due/    ← Cards due for review today
  POST   /api/flashcards/{id}/review/       ← {quality: 4} → update SRS data

  GET    /api/search/?q=etcd                ← Full-text search (use Django's SearchVector)

  POST   /api/auth/register/
  POST   /api/auth/login/                   ← Returns JWT
  POST   /api/auth/refresh/

Use django-rest-framework-simplejwt for auth. Use django-cors-headers for CORS.
Use drf-spectacular for auto-generated OpenAPI docs.

PHASE D — ADMIN CUSTOMIZATION

Register all models in Django admin with:
  - list_display for key fields
  - search_fields for content search
  - list_filter for level, domain
  - Inline models: Questions inside Quiz, ContentComponents inside Section

SETUP INSTRUCTIONS:
  - requirements.txt with all dependencies + versions
  - settings.py with PostgreSQL, DRF, JWT, CORS configuration
  - urls.py with all API routes
  - Brief README with: python manage.py migrate && python manage.py import_course_data course-data.json && python manage.py runserver
