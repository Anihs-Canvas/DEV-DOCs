─── 1B. JAVASCRIPT AS STANDALONE MODULES ──────────────────────────────────────

Write every interactive feature as an independent class/object that takes
a DOM element as its mount point. This makes React extraction trivial:

  // sidebar.js
  class Sidebar {
    constructor(containerEl, courseData) {
      this.container = containerEl;
      this.data = courseData;
      this.render();
    }
    render() { /* builds sidebar-tree from courseData */ }
    expandAll() { /* ... */ }
    filter(query) { /* fuzzy search */ }
  }

  // quiz-engine.js
  class QuizEngine {
    constructor(containerEl, quizData) {
      this.container = containerEl;
      this.questions = quizData.questions;
      this.score = 0;
      this.render();
    }
    submitAnswer(questionId, answerId) { /* ... */ }
    getResults() { /* ... */ }
  }

  // progress-tracker.js
  class ProgressTracker {
    constructor(storageKey) {
      this.storage = new LocalStorageAdapter(storageKey);
    }
    markSectionComplete(partId, chapterId, sectionId) { /* ... */ }
    getOverallProgress() { /* returns { completed, total, percentage } */ }
    getResumePoint() { /* returns { partId, chapterId, sectionId } */ }
  }

Every class:
  ✅ Has ONE responsibility
  ✅ Takes data as input (doesn't hardcode content)
  ✅ Exposes a clean public API
  ✅ Stores state via an abstracted storage adapter
  ✅ Can be lifted into React with minimal rewrites

─── 3A. DJANGO DATA MODELS ───────────────────────────────────────────────────

These models map DIRECTLY to the course-data.json structure from Phase 1.
This is why Phase 1's JSON design is so critical.

  # models/course.py
  class Course(models.Model):
      """A single course (e.g., 'CKA Complete Guide')"""
      slug = models.SlugField(unique=True)
      title = models.CharField(max_length=255)
      description = models.TextField()
      version = models.CharField(max_length=20)
      total_hours = models.DecimalField(max_digits=4, decimal_places=1)
      is_published = models.BooleanField(default=False)
      created_at = models.DateTimeField(auto_now_add=True)
      updated_at = models.DateTimeField(auto_now=True)


  class Part(models.Model):
      """A major section (e.g., 'Part 1: Foundation')"""
      course = models.ForeignKey(Course, on_delete=models.CASCADE, related_name='parts')
      number = models.PositiveSmallIntegerField()
      title = models.CharField(max_length=255)
      level = models.CharField(max_length=20, choices=[('beginner','Beginner'),('intermediate','Intermediate'),('advanced','Advanced')])
      cka_domains = models.JSONField(default=list)       # ["Cluster Architecture"]
      cka_weight = models.PositiveSmallIntegerField(default=0)  # 25
      order = models.PositiveSmallIntegerField()

      class Meta:
          ordering = ['order']


  class Chapter(models.Model):
      """A single chapter within a part"""
      part = models.ForeignKey(Part, on_delete=models.CASCADE, related_name='chapters')
      number = models.PositiveSmallIntegerField()
      title = models.CharField(max_length=500)
      duration = models.CharField(max_length=50)          # "~1.5 hours"
      level = models.CharField(max_length=20)
      learning_objectives = models.JSONField(default=list)
      order = models.PositiveSmallIntegerField()


  class Section(models.Model):
      """A content section within a chapter"""
      chapter = models.ForeignKey(Chapter, on_delete=models.CASCADE, related_name='sections')
      section_id = models.CharField(max_length=50)        # "s1-1"
      title = models.CharField(max_length=500)
      section_type = models.CharField(max_length=50)      # "concept", "comparison", "quiz", "lab"
      content_html = models.TextField()                   # Rendered HTML
      content_json = models.JSONField()                   # Structured components array
      order = models.PositiveSmallIntegerField()


  class ContentComponent(models.Model):
      """A single UI component within a section (code block, diagram, info box, etc.)"""
      section = models.ForeignKey(Section, on_delete=models.CASCADE, related_name='components')
      component_type = models.CharField(max_length=50)    # "info-box", "code-block", "diagram"
      variant = models.CharField(max_length=50, blank=True)  # "tip", "note", "warning"
      title = models.CharField(max_length=500, blank=True)
      body_html = models.TextField(blank=True)
      code = models.TextField(blank=True)                 # For code blocks
      language = models.CharField(max_length=50, blank=True)
      filename = models.CharField(max_length=255, blank=True)
      metadata = models.JSONField(default=dict)           # Any extra data
      order = models.PositiveSmallIntegerField()


  class Quiz(models.Model):
      """A quiz attached to a chapter"""
      chapter = models.OneToOneField(Chapter, on_delete=models.CASCADE, related_name='quiz')
      shuffle = models.BooleanField(default=True)
      passing_score = models.PositiveSmallIntegerField(default=70)


  class Question(models.Model):
      """A single quiz question"""
      quiz = models.ForeignKey(Quiz, on_delete=models.CASCADE, related_name='questions')
      text = models.TextField()
      explanation = models.TextField(blank=True)
      domain = models.CharField(max_length=100, blank=True)      # CKA domain
      difficulty = models.CharField(max_length=20, choices=[('easy','Easy'),('medium','Medium'),('hard','Hard')])
      order = models.PositiveSmallIntegerField(default=0)


  class AnswerOption(models.Model):
      """Multiple choice answer"""
      question = models.ForeignKey(Question, on_delete=models.CASCADE, related_name='options')
      text = models.TextField()
      is_correct = models.BooleanField(default=False)
      order = models.PositiveSmallIntegerField(default=0)

  # models/flashcard.py
  class FlashcardDeck(models.Model):
      """A named collection of flashcards"""
      course = models.ForeignKey(Course, on_delete=models.CASCADE, related_name='flashcard_decks')
      name = models.CharField(max_length=255)              # "Core Concepts"
      slug = models.SlugField()


  class Flashcard(models.Model):
      """A single flashcard"""
      deck = models.ForeignKey(FlashcardDeck, on_delete=models.CASCADE, related_name='cards')
      front = models.TextField()
      back = models.TextField()
      chapter = models.ForeignKey(Chapter, null=True, on_delete=models.SET_NULL)
      order = models.PositiveSmallIntegerField(default=0)

  # models/progress.py
  class UserProgress(models.Model):
      """Tracks which sections a user has completed"""
      user = models.ForeignKey('auth.User', on_delete=models.CASCADE, related_name='progress')
      section = models.ForeignKey(Section, on_delete=models.CASCADE)
      completed = models.BooleanField(default=False)
      completed_at = models.DateTimeField(null=True, blank=True)
      time_spent_seconds = models.PositiveIntegerField(default=0)

      class Meta:
          unique_together = ['user', 'section']


  class QuizAttempt(models.Model):
      """Records a quiz attempt"""
      user = models.ForeignKey('auth.User', on_delete=models.CASCADE)
      quiz = models.ForeignKey(Quiz, on_delete=models.CASCADE)
      score = models.PositiveSmallIntegerField()            # e.g., 80
      total = models.PositiveSmallIntegerField()            # e.g., 10
      passed = models.BooleanField()
      answers = models.JSONField()                          # {question_id: answer_id}
      attempted_at = models.DateTimeField(auto_now_add=True)


  class FlashcardReview(models.Model):
      """Spaced repetition review history (SM-2 algorithm)"""
      user = models.ForeignKey('auth.User', on_delete=models.CASCADE)
      flashcard = models.ForeignKey(Flashcard, on_delete=models.CASCADE)
      ease_factor = models.FloatField(default=2.5)
      interval_days = models.PositiveSmallIntegerField(default=0)
      repetitions = models.PositiveSmallIntegerField(default=0)
      next_review_at = models.DateTimeField()
      last_review_at = models.DateTimeField(null=True)
      last_quality = models.PositiveSmallIntegerField(default=0)  # 0-5


  class UserCourseEnrollment(models.Model):
      """Tracks enrollment + overall course progress"""
      user = models.ForeignKey('auth.User', on_delete=models.CASCADE)
      course = models.ForeignKey(Course, on_delete=models.CASCADE)
      enrolled_at = models.DateTimeField(auto_now_add=True)
      completed_at = models.DateTimeField(null=True, blank=True)
      last_accessed_at = models.DateTimeField(null=True)
      last_section = models.ForeignKey(Section, null=True, on_delete=models.SET_NULL)

      class Meta:
          unique_together = ['user', 'course']

─── 3D. CONTENT IMPORT STRATEGY ───────────────────────────────────────────────

The `import_course_data` management command loads course-data.json directly:

  # management/commands/import_course_data.py

  python manage.py import_course_data course-data.json

This command:
  1. Reads the JSON file (same one from Phase 1/2)
  2. Creates/updates Course, Part, Chapter, Section, ContentComponent records
  3. Creates Quiz, Question, AnswerOption records
  4. Creates FlashcardDeck, Flashcard records
  5. Uses `update_or_create` so it's idempotent (safe to re-run)
  6. Validates data integrity before committing
  7. Reports: "Imported 11 parts, 40 chapters, 350+ sections, 400+ questions"

This means the EXACT SAME course-data.json powers:
  ✓ Phase 1: Static HTML (embedded in <script> tag)
  ✓ Phase 2: React SPA (fetched from /public/ or API)
  ✓ Phase 3: Django LMS (imported into database)

     This makes React conversion a 15-minute refactor per module, not a rewrite.

  3. ⭐ USE CSS CUSTOM PROPERTIES AS YOUR DESIGN TOKEN LAYER
     They carry through unchanged from Phase 1 → Phase 2 → Phase 3.

  4. ⭐ DON'T BUILD THE FULL LMS IN PHASE 1
     The monolithic HTML is a CONTENT PROTOTYPE. Keep its JS simple.
     The fancy features (auth, database, API) belong in Phase 3.

  5. ⭐ DESIGN DJANGO MODELS TO MATCH COURSE-DATA.JSON 1:1
     Every key in the JSON should have a corresponding model field.
     This makes import/export trivial.

  6. ⭐ USE update_or_create() FOR IDEMPOTENT IMPORTS
     You'll re-import content many times during development.
     Make sure it doesn't duplicate data.

  7. ⭐ KEEP THE ORIGINAL cka.html AS CONTENT SOURCE OF TRUTH
     Until the LMS is live with all features, the monolithic HTML
     remains the authoritative version. Never delete it.

  8. ⭐ PLAN FOR MULTI-COURSE FROM DAY ONE
     Don't hardcode "CKA" into your models. Design for:
     Course → Parts → Chapters. This lets you add CKAD, CKS, KCNA later.

  9. ⭐ THE EXAM SIMULATOR IS YOUR KILLER FEATURE
     Anyone can write a study guide. A timed, weighted, domain-tagged
     exam simulator with "Are you ready?" prediction is what gets users
     to pay for the platform.

  10. ⭐ BUILD IN PUBLIC WITH FEATURE FLAGS
      Use Django's contribution system or a feature flag library.
      Ship the content browser first, add quizzes next, flashcards after.
      Don't wait until everything is perfect.
