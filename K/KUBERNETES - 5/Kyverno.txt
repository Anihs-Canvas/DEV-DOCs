    │     Mutate policy behaviors        Mutate = modify existing  │

    │  5. Not knowing the Kyverno CLI    kyverno apply, kyverno    │
    │     for testing policies           test for CI/CD pipelines  │

    │  6. Ignoring Policy Reports        PolicyReport CRs show     │
    │     (they track violations)        pass/fail/warn results    │

    │  7. Not understanding Exceptions   Exceptions = exclude      │

    1.1  The Problem Kubernetes Policies Solve
         - Kubernetes is powerful but has no built-in governance
         - The Wild West: anyone with kubectl access can do anything
         - Real-world scenario: Deploying anihpj without policies —
           developer accidentally uses :latest tag, no resource limits,
           secrets committed to Git in plaintext

    1.2  Policy-as-Code Defined
         - What is Policy-as-Code? Declarative rules for your cluster
         - Why YAML? Same language as Kubernetes — no new language to learn
         - Key benefit: Policies version-controlled in Git (GitOps for governance)

         [INFO BOX: Policy-as-Code = "If this, then that" rules for K8s]
         ┌─────────────────────────────────────────────────────────────────────┐
         │  📋 POLICY-AS-CODE — THE 3-INGREDIENT FORMULA                       │
         │                                                                      │
         │     IF (condition)         THEN (action)          FOR (resource)     │
