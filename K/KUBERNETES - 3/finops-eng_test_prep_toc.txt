F.1 What Is FinOps & Why Does It Matter? 🟢 Novice
    • The "Cloud Bill Shock" Problem — Why $500/mo becomes $50,000/mo overnight
    • FinOps = Finance + DevOps = Bringing financial accountability to cloud spending
    • The 6 FinOps Principles — The DNA of every FinOps practice:
        1. Teams need to collaborate (Finance + Engineering + Product + Leadership)
        2. Decisions are driven by business value of cloud
        3. Everyone takes ownership of their cloud usage
        4. FinOps data should be accessible and timely
        5. A centralized team drives FinOps
        6. Take advantage of the variable cost model of cloud
    • The FinOps Lifecycle — The never-ending 3-phase cycle:
        📊 INFORM: See it → Know what you're spending and why
        ⚡ OPTIMIZE: Save it → Reduce waste and commit to better rates
        🎯 OPERATE: Govern it → Make cost-conscious decisions continuously
    • Why anihpj/jobpost is your learning lab:
        - Django web tier (EKS): Variable traffic = variable compute cost
        - REST API tier: Per-request cost model
        - PostgreSQL (RDS): Steady-state cost + backup storage
        - Redis cache (ElastiCache): Memory-tiered pricing
        - S3 assets: Storage class optimization opportunity
        - CloudFront CDN: Data transfer cost optimization
    • Real-world FinOps impact: Airbnb saved 40%, Netflix saved 25%, Spotify saved 30%
    🟢 Novice | Visual: FinOps Lifecycle Mermaid diagram + 6 Principles card set

F.2 Cloud Economics 101 — How Cloud Pricing ACTUALLY Works 🟢 Novice
    • The 5 Cloud Cost Dimensions — Every service charges by some combination of:
        1. COMPUTE TIME: Per-second/per-hour VM/container runtime
        2. STORAGE CAPACITY: Per-GB stored, per-IOPS
        3. DATA TRANSFER: Per-GB egress (ingress usually free)
        4. LICENSING: Per-core software licensing
        5. API CALLS: Per-million requests/operations
    • AWS, Azure, GCP Pricing Models Compared:
        - On-Demand: Pay-as-you-go (highest rate, zero commitment)
        - Reserved/Commitment: 1-3 year commitment (30-72% discount)
        - Spot/Preemptible: Bid on spare capacity (60-90% discount, can be reclaimed)
        - Savings Plans: Commit to $/hr spend (flexible across instance family)
        - Enterprise Agreements: Custom negotiated pricing
    • The "Penny Wise, Pound Foolish" Trap — Why cheapest ≠ best:
        - t3.nano ($0.0052/hr) vs t3.medium ($0.0416/hr)
        - The nano is 87% cheaper BUT: max 2 vCPU credits, 0.5GB RAM → crashes under load
    • Cloud Provider Free Tiers & Credits — AWS Free Tier, GCP $300 credit, Azure $200
    • The anihpj/jobpost Monthly Bill Breakdown (before FinOps):

F.3 FinOps Core Capabilities & Framework 🟢 Novice
    • The FinOps Maturity Model (Crawl → Walk → Run):
        CRAWL: Basic visibility, manual reporting, ad-hoc cost reviews
        WALK: Automated reporting, tagging strategy, RI/Savings Plan procurement
        RUN: Real-time cost data, automated optimization, CI/CD cost gates
    • The 18 FinOps Capabilities (across the 3 lifecycle phases):
        📊 INFORM Phase (Data & Analytics):
          - Data Ingestion & Normalization
          - Cost Allocation (Tagging, Hierarchy)
          - Reporting & Analytics (Dashboards)
          - Anomaly Detection
          - Forecasting
          - Budget Management
        ⚡ OPTIMIZE Phase:
          - Rate Optimization (RIs, Savings Plans, CUDs, Spot)
          - Usage Optimization (Rightsizing, Scheduling, Waste)
          - Workload Management & Automation
          - Architecture Optimization (Serverless, Containerization)
        🎯 OPERATE Phase:
          - FinOps Culture & Enablement
          - Chargeback & Showback
          - FinOps Education & Training
          - Establishing a FinOps Decision & Accountability Structure
          - Cloud Policy & Governance
          - Intersecting Disciplines (ITSM, ITFM, Security)
    • The FinOps Personas — Who does what:
        - EXECUTIVES: Focus on accountability, transparency, and strategy
        - FINANCE: Focus on financial accuracy, forecasting, and procurement
        - ENGINEERING: Focus on building cost-efficient architectures
        - PRODUCT: Focus on feature-driven consumption and ROI analysis
        - FINOPS PRACTITIONER: The bridge between all personas

F.5 Cloud Billing Data — Where Your Cost Data Lives 🟢 Novice
    • AWS Cost & Usage Report (CUR) — The source of ALL truth:
        - What it contains: 300+ columns of cost data per resource per hour
        - CUR vs CUR 2.0 (newer, simpler, faster)
        - Where it goes: S3 bucket → Athena queries → QuickSight dashboards
        - Line item types: Usage, Tax, Fee, Credit, Refund, SavingsPlanCoveredUsage
    • AWS Cost Explorer — The "quick view" of your cloud spend
    • AWS Budgets — Set thresholds, get alerts (and auto-remediate!)
    • AWS Compute Optimizer — ML-powered rightsizing recommendations
    • Azure Cost Management + Billing — Microsoft's FinOps portal
    • GCP Cloud Billing + Cost Table — Google's cost analytics
    • The anihpj/jobpost CUR Sample:
        SELECT line_item_usage_account_id,
               line_item_product_code,
               line_item_usage_type,
               line_item_unblended_cost,
               line_item_usage_start_date
        FROM "anihpj_cur"
        WHERE line_item_product_code = 'AmazonRDS'
