    WHAT IS FINOPS?
    ───────────────
    FinOps (Financial Operations) is the operating model for cloud financial
    management. It brings together Finance, Engineering, and Business teams to
    drive financial accountability, optimize cloud costs, and accelerate business
    value. Think of it as "DevOps for cloud spending."

    THE SIX FINOPS PRINCIPLES
    ─────────────────────────
    ┌─────────────────────────────────────────────────────────────┐
    │  ① Teams need to collaborate                                │
    │  ② Decisions are driven by business value of cloud          │
    │  ③ Everyone takes ownership of their cloud usage            │
    │  ④ FinOps data should be accessible and timely              │
    │  ⑤ A centralized team drives FinOps                        │
    │  ⑥ Take advantage of the variable cost model of cloud      │
    └─────────────────────────────────────────────────────────────┘

    WHY FINOPS MATTERS (With anihpj Example)
    ────────────────────────────────────────
    Before FinOps: The engineering team deploys anihpj on K8s with 10 replicas,
    r5.xlarge nodes, and a $2000/month RDS instance. Nobody tracks costs. At end
    of quarter, finance asks "Why is our cloud bill $18,000?"

    With FinOps: Engineering knows each anihpj deployment costs ~$4.20/hour.
    Finance allocates costs to the jobpost team. Business sees unit cost per job
    posting = $0.003. Everyone optimizes: rightsizing saves $3,200/month.

    KEY FINOPS FORMULAS — MUST MEMORIZE FOR THE EXAM
    ────────────────────────────────────────────────
    ┌─────────────────────────────────────────────────────────────────┐
    │  FORMULA                     CALCULATION              EXAMPLE    │
    │  ──────────────────────────  ───────────────────────  ───────── │
    │  Effective Savings Rate   =  (OnDemand - Actual)     (100-65)/  │
    │  (ESR)                       / OnDemand × 100        100 = 35%  │
    │  ──────────────────────────  ───────────────────────  ───────── │
    │  RI/SP Coverage Rate      =  RI/SP Compute Spend     $4,000 /   │
    │                              / Total Compute Spend    $6,000     │
    │                                                      = 67%      │
    │  ──────────────────────────  ───────────────────────  ───────── │
    │  Amortized Cost            =  (Upfront Payment +     ($1,200 +  │
    │                              Monthly × 36) / 36      $0×36)/36  │
    │                                                      = $33.33/mo│
    │  ──────────────────────────  ───────────────────────  ───────── │
    │  Unit Cost                  =  Total Cloud Spend /    $15,000 /  │
    │                              # of Business Units     5,000,000  │
    │                                                      jobs =     │
    │                                                      $0.003/job │
    │  ──────────────────────────  ───────────────────────  ───────── │

    │  │ 📋 Commitment: 1 or 3 YEARS — instance family locked     │    │
    │  │ ✅ Best For: Steady-state predictable workloads           │    │
    │  │ ❌ Not For: Workloads that may change instance families   │    │

    │  │ 📋 Commitment: $/hr spend for 1 or 3 years               │    │
    │  │ ✅ Best For: ANY compute (EC2, Lambda, Fargate, EKS)     │    │
    │  │ ❌ Not For: RDS, ElastiCache (use RI for those)          │    │
    │  │ 🎯 anihpj: All compute across ALL accounts/regions       │    │

    FINOPS ANTI-PATTERNS — HALL OF SHAME
    ────────────────────────────────────
    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                  │
    │  TOP 10 ANTI-PATTERNS THAT DESTROY CLOUD BUDGETS:                │
    │                                                                  │
    │  ┌───────────────────────────────────────────────────────────┐  │
    │  │  #1 🧟 ZOMBIE RESOURCES                                    │  │
    │  │  Unused load balancers, IPs, volumes left running          │  │
    │  │  IMPACT: $500-2,000/month in wasted spend                  │  │
    │  │  FIX: Cloud Custodian "reaper" policy, weekly audit        │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #2 🐌 "JUST IN CASE" SIZING                               │  │
    │  │  "Let's use r5.2xlarge just in case we get traffic"        │  │
    │  │  IMPACT: 3-5× overpaying for unused capacity               │  │
    │  │  FIX: Rightsize based on actual usage data (30-day window) │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #3 🏷️ TAG CHAOS                                           │  │
    │  │  No tagging standard, "CostCenter=???" everywhere          │  │
    │  │  IMPACT: 40%+ unallocated spend, no accountability         │  │
    │  │  FIX: Enforce tags via SCP/Azure Policy, auto-tag with IaC │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #4 📦 K8s WITHOUT LIMITS                                   │  │
    │  │  Pods with no resource limits = can consume entire node    │  │
    │  │  IMPACT: Noisy neighbor kills other pods, wastes capacity  │  │
    │  │  FIX: Kyverno policy: block pods without limits            │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #5 🔓 DEV/STAGING 24/7                                     │  │
    │  │  Dev environments running Sat-Sun with zero usage          │  │
    │  │  IMPACT: 30% of dev spend is nights/weekends               │  │
    │  │  FIX: Auto-shutdown schedule (Instance Scheduler, K8s job) │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #6 💾 SNAPSHOT ARMAGEDDON                                  │  │
    │  │  10,000 EBS snapshots accumulated over 3 years             │  │
    │  │  IMPACT: $500/month in snapshot storage, nobody knows why  │  │
    │  │  FIX: Lifecycle policy: delete snapshots older than 30 days│  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #7 🌐 CROSS-AZ DATA TRANSFER BLINDNESS                     │  │
    │  │  Pods talking to DB across AZs for every query             │  │
    │  │  IMPACT: $600/month in invisible network costs             │  │
    │  │  FIX: Pod affinity to co-locate app + DB in same AZ        │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #8 📊 OBSERVABILITY OVERKILL                               │  │
    │  │  90-day log retention with debug-level logging everywhere  │  │
    │  │  IMPACT: Logging costs exceed compute costs!               │  │
    │  │  FIX: Tiered logging: ERROR=90d, INFO=7d, DEBUG=1d        │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #9 💰 RI/SP PURCHASED AND FORGOTTEN                        │  │
    │  │  Bought 3-year RI, then migrated to Graviton 6 months later│  │
    │  │  IMPACT: Paying for unused RI + new instances (double pay) │  │
    │  │  FIX: Monthly RI utilization review, sell unused on market │  │
    │  ├───────────────────────────────────────────────────────────┤  │
    │  │  #10 🚫 NO BUDGET ALERTS                                    │  │
    │  │  No one notices spend until the monthly bill arrives       │  │
    │  │  IMPACT: Cannot react to spikes in real-time               │  │
    │  │  FIX: Budget alerts at 50%, 80%, 100% with Slack/email     │  │
