F.3 The Three Signals Deep Dive — Traces, Metrics, Logs
    • TRACES: A trace = a journey of a request through your system
        - Span: a single unit of work (function call, HTTP request, DB query)
        - Trace ID: links all spans of the same request together
        - Span context: Trace ID + Span ID + Trace Flags + Trace State
        - Parent-child relationships: how spans form a waterfall/tree
        - Span attributes: key-value metadata (http.method, db.statement, user.id)
        - Span events: timestamped annotations within a span (exception, log event)
        - Span status: OK, Error, Unset
        - Span kind: Client, Server, Internal, Producer, Consumer
    • METRICS: A metric = a measurement of something over time
        - Counter: only goes UP (request count, error count)
        - UpDownCounter: can go UP or DOWN (active connections, queue depth)
        - Histogram: distribution of values (request latency, payload size)
        - Gauge: point-in-time value (CPU %, memory usage)
        - Instruments vs Instruments — synchronous (callback-based) vs asynchronous (polled)
        - Exemplars: linking a metric data point to a trace (the "WHY" behind the spike)
    • LOGS: A log = a timestamped record of an event
        - Log data model: Timestamp, Severity, Body, Attributes, TraceId, SpanId
        - Log correlation: Injecting TraceId + SpanId into logs
        - Structured logging vs unstructured — JSON vs raw text
        - Log severity levels: TRACE, DEBUG, INFO, WARN, ERROR, FATAL
        - Why logs are most powerful when CORRELATED with traces

    • OTel vs Fluentd/Fluent Bit (logs only) — OTel unifies log collection with trace correlation
    • OTel vs proprietary agents (Datadog, New Relic, Dynatrace) — vendor-neutral STANDARD
    • Comparison table: Tool | Signals | Vendor Lock-in | Community | CNCF Status
    • The "OTel advantage": instrument ONCE, export ANYWHERE (no vendor lock-in!)
    • When to use OTel + existing tools together (defense in depth)
    • The OTel maturity model: Basic instrumentation → Full correlation → Business observability
    • Real-world adoption: Who uses OTel? (Shopify, Uber, Netflix, Microsoft, AWS, Google)
