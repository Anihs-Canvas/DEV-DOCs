🎯 CNPE Exam Strategy

⏱️
Exam Format

2 hours, performance-based. Live terminal in a browser. 15-20 scenario-based tasks. No multiple choice — everything is hands-on.

🎯
Passing Score

Typically 66-75% (varies). Focus heaviest on Domain 2 (GitOps/CD — 25%) and Domain 3 (Platform APIs — 25%).

💻
Environment

Multiple Kubernetes clusters provided. SSH into nodes, run kubectl, deploy operators, configure GitOps, debug pipelines.

📋
Allowed Resources

kubernetes.io/docs, helm.sh/docs, argo-cd.readthedocs.io, prometheus.io/docs — browser tabs allowed on the exam.

Top 5 Exam Tips
  • Master imperative commands first — speed matters on the exam
  • Know your GitOps cold — Argo CD and Flux make up 25% of the exam
  • Practice CRD creation — from scratch, with validation schemas
  • Debug fast — kubectl describe, kubectl logs, kubectl get events
  • Time management — skip hard tasks first, come back with remaining time
