    1.2  What is an Internal Developer Portal (IDP)?
         • Definition: A unified interface for all your infrastructure
         • The "single pane of glass" concept
         • Software Catalog — the beating heart of Backstage
         • Software Templates — golden paths to production
         • TechDocs — documentation that lives with your code
         • Plugins — the extensibility superpower
         • How anihpj benefits: one place for services, docs, CI/CD, monitoring

    1.3  Backstage Architecture — The Big Picture
         • Frontend: React-based UI (TypeScript)
         • Backend: Node.js/Express API server
         • Plugin architecture: frontend + backend plugins
         • Database: PostgreSQL (default) or SQLite
         • app-config.yaml — the central configuration hub
         • The Scaffolder — template execution engine
         • Search engine integration (Elasticsearch, PostgreSQL)
         • Architecture diagram: Frontend ↔ Backend ↔ DB ↔ External Services

    4.1  What is the Software Catalog?
         • Central registry of all software in your organization
         • Entity-based — everything is an Entity
         • YAML-driven configuration (catalog-info.yaml)
         • Relationships between entities
         • The "source of truth" concept
         • How anihpj/jobpost entities appear in the catalog

    4.2  Entity Kinds — The Building Blocks
         • Component — a piece of software (service, website, library)
         • API — an API boundary (OpenAPI, AsyncAPI, gRPC)
         • Resource — infrastructure (database, queue, bucket)
         • System — a collection of Components + Resources
         • Domain — a collection of Systems
         • User & Group — people and teams
         • Template — Software Templates (special kind)

    4.3  Entity YAML Structure (catalog-info.yaml)
         • apiVersion: backstage.io/v1alpha1
         • kind: Component (which entity kind)
         • metadata: name, namespace, labels, annotations, tags
         • spec: type, lifecycle, owner, system, dependsOn, providesApis
         • Full anihpj Component YAML example
         • Full jobpost API YAML example

    4.4  Entity Lifecycle
         • experimental → production → deprecated → retired
         • How lifecycle affects catalog visibility
         • Best practices for lifecycle management
