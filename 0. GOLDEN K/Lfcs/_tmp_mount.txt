                <h3>mount</h3>
                <div class="api-meta"><span class="method-badge method-post">MOUNT</span><span class="tag">Disk</span><span class="tag">Core</span><span class="tag">LFCS Domain 2</span></div>
                <p class="api-subtitle">Mount filesystems — attach storage devices to the directory tree</p>
                <div class="api-description"><p><code class="inline">mount</code> attaches a filesystem (partition, network share, ISO image) to a directory (mount point). Without arguments, it lists all mounted filesystems. Essential for making storage accessible. Permanent mounts go in <code>/etc/fstab</code>.</p></div>
                <h4 class="syntax-header">Syntax</h4>
                <pre><code class="language-bash">mount [OPTIONS] DEVICE MOUNTPOINT

# Common patterns:
mount    # List all mounted filesystems
sudo mount /dev/sdb1 /mnt/data    # Mount a device
sudo mount -o remount,rw /    # Remount root read-write
sudo mount -o ro /dev/sdc1 /mnt/readonly    # Mount read-only
sudo mount -t ext4 /dev/sdb1 /mnt/data    # Specify filesystem type
sudo mount -o loop image.iso /mnt/iso    # Mount ISO file
sudo mount -a    # Mount all entries in fstab</code></pre>
