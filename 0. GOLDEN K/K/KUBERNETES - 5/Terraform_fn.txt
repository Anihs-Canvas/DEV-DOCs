  │  J.1.1  format(spec, values...)                                             │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Produces a formatted string from a format specification      │
  │                and a list of values. Works like printf/sprintf.             │
  │  Syntax:       format(spec, val1, val2, ...)                                │
  │  Parameters:   spec   — Format string with %s (string), %d (int),           │
  │                         %f (float), %t (bool), %v (auto-detect)             │
  │                values — Comma-separated list of values to format            │
  │  Return:       String — the formatted output                                │
  │                                                                             │
  │  Examples:                                                                  │
  │  1.  format("Hello, %s!", "World")                          → "Hello, World!"│
  │  2.  format("Instance %s has %d CPUs", "web-01", 4)        → "Instance web-01 has 4 CPUs"│
  │  3.  format("Subnet %s: %s/%s", "public", "10.0.1.0", "24") → "Subnet public: 10.0.1.0/24"│
  │  4.  format("Tag: Name=%s, Env=%s", var.name, var.env)     → "Tag: Name=web, Env=prod"│
  │  5.  format("Port: %d→%d (%s)", 80, 8080, "tcp")           → "Port: 80→8080 (tcp)"│
  └─────────────────────────────────────────────────────────────────────────────┘

  │  J.1.2  formatlist(spec, list_of_lists...)                                   │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Applies format() to each element across multiple lists,       │
  │                producing a new list of formatted strings.                    │
  │  Syntax:       formatlist(spec, list1, list2, ...)                           │
  │  Parameters:   spec   — Format string (same specifiers as format())          │
  │                lists  — One or more lists; elements at same index paired     │
  │  Return:       List of strings — each element formatted                     │
  │                                                                             │
  │  Examples:                                                                  │
  │  1.  formatlist("%s-%s", ["web","db"], ["01","02"])     → ["web-01","db-02"]│
  │  2.  formatlist("%s:%d", ["http","ssh"], [80,22])      → ["http:80","ssh:22"]│

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.1  tostring(value)                                                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Converts any value to its string representation.             │
  │  Syntax:       tostring(value)                                               │

  │  1.  tostring(42)                                        → "42"              │

  │  4.  tostring(aws_vpc.main.id)                           → "vpc-abc12345"    │
  │  5.  "${tostring(var.port)}"                             → "8080"            │

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.2  tonumber(value)                                                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Converts a string/number/bool to a number. Fails if not valid.│
  │                Use try(tonumber(x), default) for safe conversion.            │
  │  Syntax:       tonumber(value)                                               │
  │  Return:       Number                                                        │
  │  Examples:                                                                  │
  │  1.  tonumber("42")                                      → 42                │
  │  2.  tonumber("3.14")                                    → 3.14              │
  │  3.  tonumber(true)                                      → 1                 │
  │  4.  tonumber(var.string_port) + 1                       → 8081              │
  │  5.  try(tonumber(var.optional), 0)                      → 0 (safe fallback) │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.3  tobool(value)                                                        │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Converts a string or number to boolean. "true"/"1" → true.   │
  │                "false"/"0"/"" → false. Fails on invalid input.              │
  │  Syntax:       tobool(value)                                                 │
  │  Return:       Boolean                                                       │
  │  Examples:                                                                  │
  │  1.  tobool("true")                                      → true              │
  │  2.  tobool("false")                                     → false             │
  │  3.  tobool(1)                                           → true              │
  │  4.  tobool(var.enable_monitoring)                       → true/false        │
  │  5.  tobool(coalesce(var.flag, "false"))                 → (safe conversion) │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.4  tolist(value)                                                        │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Converts a set or single value to a list. For sets, order is  │
  │                arbitrary (use sort() if needed).                            │
  │  Syntax:       tolist(value)                                                 │
  │  Return:       List                                                          │
  │  Examples:                                                                  │
  │  1.  tolist(["a","b"])                                   → ["a","b"]         │
  │  2.  tolist(toset(["b","a","b"]))                        → ["a","b"]         │
  │  3.  tolist(fileset("${path.module}", "*.tf"))           → (files as list)  │
  │  4.  [for i in tolist(var.things) : upper(i)]           → (iterate safely)  │
  │  5.  element(tolist(data.aws_subnet.matching.ids), 0)    → (first element)  │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.5  toset(value)                                                         │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Converts a list to a set — removes duplicates automatically.  │
  │                Sets can be used with for_each just like maps.                │
  │  Syntax:       toset(value)                                                  │
  │  Return:       Set — unique elements                                        │
  │  Examples:                                                                  │
  │  1.  toset(["a","b","a"])                                 → ["a","b"] (set)  │
  │  2.  toset(var.subnet_ids)                                → (unique subnets) │
  │  3.  toset(concat(var.list_a, var.list_b))                → (union as set)  │
  │  4.  for_each = toset(distinct(var.ports))               → (iterate unique)  │
  │  5.  contains(toset(var.values), "admin")                 → (fast lookup)   │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.6  tomap(value)                                                         │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Converts an object value to a map. Most Terraform values are  │
  │                already maps, but this ensures the type.                      │
  │  Syntax:       tomap(value)                                                  │
  │  Return:       Map                                                           │
  │  Examples:                                                                  │
  │  1.  tomap({a=1, b=2})                                   → {a=1, b=2}       │
  │  2.  tomap(var.tags)                                      → (guaranteed map) │
  │  3.  lookup(tomap(var.config), "key", "default")         → (safe lookup)    │
  │  4.  tomap(try(jsondecode(var.json), {}))                → (safe JSON→map)  │
  │  5.  merge(tomap(var.defaults), tomap(var.overrides))    → (merged maps)    │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.7  can(expression)                                                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Evaluates an expression. Returns true if it succeeds (no      │
  │                error), false if it produces an error. CRITICAL for           │
  │                validation blocks and safe conditional logic.                 │
  │  Syntax:       can(expression)                                               │
  │  Return:       Boolean — true if expression evaluates without error         │
  │  Examples:                                                                  │
  │  1.  can(regex("^[a-z]+$", var.name))                    → true (valid)      │
  │  2.  can(tonumber("abc"))                                → false             │
  │  3.  can(var.optional_map["key"])                        → true/false        │
  │  4.  can(regex("^[a-z0-9.-]+$", var.domain)) for validation block           │
  │  5.  condition = can(regex("^\\d+$", var.port))         → (port is numeric) │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.6.8  try(expressions...) — Full Deep Dive                                 │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Evaluates each argument in order. Returns the FIRST one that  │
  │                doesn't produce an ERROR. Unlike coalesce() which checks for  │

  │  Return:       Any — first non-error value                                  │
  │  Examples:                                                                  │

  │  5.  try(data.aws_ssm.db_pass.value, random_password.fallback.result)        │

  │  J.7.1  md5(string)                                                          │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Returns the MD5 hash of a string as a hex string. Not for     │

  │  J.7.2  sha256(string) / sha512(string)                                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Returns the SHA-256 (64-char) or SHA-512 (128-char) hex hash. │
  │  Syntax:       sha256(string) / sha512(string)                               │
  │  Return:       String — hex hash                                            │
  │  Examples:                                                                  │
  │  1.  sha256("hello")                                     → (64-char hash)    │
  │  2.  sha512(file("important.txt"))                       → (integrity check) │
  │  3.  base64sha256("hello")                               → (base64 encoded)  │
  │  4.  sha256(jsonencode(var.tags))                         → (tags fingerprint)│
  │  5.  sha256(join(",", [for k,v in var.config : "${k}=${v}"]))                │
  └─────────────────────────────────────────────────────────────────────────────┘

  │  J.7.3  uuid() / uuidv5(namespace, name)                                     │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  uuid() generates a random UUID v4. uuidv5() generates a       │
  │                deterministic UUID v5 from namespace + name.                  │
  │  Syntax:       uuid()  /  uuidv5(namespace_uuid, name)                       │
  │  Return:       String — UUID (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)         │
  │  Examples:                                                                  │
  │  1.  uuid()                                             → "550e8400-e29b..." │
  │  2.  uuidv5("dns", "anihpj.com")                        → (deterministic)   │
  │  3.  resource "aws_s3_bucket" { bucket = "app-${uuid()}" }                   │
  │  4.  uuidv5("6ba7b810-9dad-11d1-80b4-00c04fd430c8", var.identifier)         │
  │  5.  ⚠️ uuid() changes on every plan — use only for truly unique names!     │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.7.4  bcrypt(string, cost)                                                 │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Returns the bcrypt hash of a string. Cost = 10-31 (higher =   │
  │                slower but more secure). Use for password hashing.            │
  │  Syntax:       bcrypt(string, cost)                                          │
  │  Return:       String — bcrypt hash ($2a$...)                               │
  │  Examples:                                                                  │
  │  1.  bcrypt("my-password", 10)                           → "$2a$10$..."      │
  │  2.  bcrypt(random_password.db.result, 12)               → (hashed password) │
  │  3.  bcrypt(var.admin_password, 15)                      → (secure admin)    │
  │  4.  bcrypt(base64encode(var.secret), 10)                → (encoded+hashed)  │
  │  5.  ⚠️ bcrypt is computationally expensive — use cost=10 for most cases   │
  └─────────────────────────────────────────────────────────────────────────────┘

  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Calculates a full host IP address within a CIDR block. hostnum│
  │                starts at 0 (network address). Negative counts from end.      │
  │  Syntax:       cidrhost(prefix, hostnum)                                     │
  │  Return:       String — full IP address                                     │
  │  Examples:                                                                  │
  │  1.  cidrhost("10.0.0.0/24", 5)                         → "10.0.0.5"         │
  │  2.  cidrhost("10.0.0.0/24", -1)                        → "10.0.0.255" (last)│
  │  3.  cidrhost(var.vpc_cidr, 0)                           → (network address) │
  │  4.  cidrhost("172.16.0.0/12", 256)                     → "172.16.1.0"       │
  │  5.  cidrhost(aws_vpc.main.cidr_block, count.index + 10) → (per-instance IP)│
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.8.2  cidrsubnet(prefix, newbits, netnum)                                  │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Calculates a subnet CIDR within a larger CIDR block by adding │
  │                newbits more bits to the prefix length. THE subnet function.  │
  │  Syntax:       cidrsubnet(prefix, newbits, netnum)                           │
  │  Return:       String — subnet CIDR                                         │
  │  Examples:                                                                  │
  │  1.  cidrsubnet("10.0.0.0/16", 8, 0)                    → "10.0.0.0/24"      │
  │  2.  cidrsubnet("10.0.0.0/16", 8, 1)                    → "10.0.1.0/24"      │
  │  3.  cidrsubnet(var.vpc_cidr, 8, count.index)           → (per-AZ subnet)   │
  │  4.  cidrsubnet("172.16.0.0/12", 4, 0)                  → "172.16.0.0/16"    │
  │  5.  [for i in range(3) : cidrsubnet(var.cidr, 4, i)]  → (generate subnets)│
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.8.3  cidrsubnets(prefix, newbits...)                                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Calculates a SEQUENCE of subnets from a prefix, allocating    │
  │                consecutive ranges. Each argument is the number of bits to add.│
  │  Syntax:       cidrsubnets(prefix, newbits1, newbits2, ...)                  │
  │  Return:       List of strings — consecutive subnet CIDRs                   │
  │  Examples:                                                                  │
  │  1.  cidrsubnets("10.0.0.0/16", 8, 8)                  → ["10.0.0.0/24","10.0.1.0/24"]│
  │  2.  cidrsubnets("10.0.0.0/16", 4, 4, 4, 4)           → ["10.0.0.0/20",...]│
  │  3.  cidrsubnets(var.vpc_cidr, 2, 2, 2, 2)             → (4 subnets)        │
  │  4.  cidrsubnets("10.0.0.0/8", 8, 8, 8)                → ["10.0.0.0/16",...]│
  │  5.  cidrsubnets(var.cidr, [for i in range(4) : 4]...) → (4 equal subnets) │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.8.4  cidrnetmask(prefix)                                                  │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Returns the subnet mask for a CIDR prefix (e.g., /24 →        │
  │                "255.255.255.0").                                             │
  │  Syntax:       cidrnetmask(prefix)                                           │
  │  Return:       String — dotted decimal netmask                              │
  │  Examples:                                                                  │
  │  1.  cidrnetmask("10.0.0.0/24")                          → "255.255.255.0"   │
  │  2.  cidrnetmask("10.0.0.0/16")                          → "255.255.0.0"     │
  │  3.  cidrnetmask(aws_vpc.main.cidr_block)                → (VPC netmask)     │
  │  4.  cidrnetmask("10.0.0.0/28")                          → "255.255.255.240" │
  │  5.  cidrnetmask("0.0.0.0/0")                            → "0.0.0.0"         │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.8.5  cidrsubnets(prefix, newbits...) — already covered at J.8.3          │
  └─────────────────────────────────────────────────────────────────────────────┘

  ║  J.9 — DATE & TIME FUNCTIONS                                               ║
  ╚══════════════════════════════════════════════════════════════════════════════╝

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.9.1  timestamp()                                                          │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Returns the current UTC timestamp in RFC 3339 format.         │
  │                Changes on EVERY plan — use cautiously for naming.           │
  │  Syntax:       timestamp()                                                   │
  │  Return:       String — UTC timestamp (e.g., "2024-01-15T10:30:00Z")       │
  │  Examples:                                                                  │
  │  1.  timestamp()                                        → "2024-01-15T10:30:00Z"│
  │  2.  "backup-${timestamp()}"                            → "backup-2024-01-15T10:30:00Z"│
  │  3.  formatdate("YYYY-MM-DD", timestamp())              → "2024-01-15"      │
  │  4.  ⚠️ timestamp() changes every plan — use only for truly dynamic names    │
  │  5.  replace(timestamp(), ":", "-")                     → "2024-01-15T10-30-00Z"│
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.9.2  formatdate(spec, timestamp)                                          │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Formats a timestamp string according to a format specifier.    │
  │                Uses Go's reference time: Mon Jan 2 15:04:05 MST 2006.       │
  │  Syntax:       formatdate(spec, timestamp)                                   │
  │  Parameters:   spec — Format string (YYYY, MM, DD, hh, mm, ss, etc.)        │
  │                timestamp — RFC 3339 timestamp string                        │
  │  Return:       String — formatted date/time                                  │
  │  Examples:                                                                  │
  │  1.  formatdate("YYYY-MM-DD", "2024-01-15T10:30:00Z")  → "2024-01-15"      │
  │  2.  formatdate("DD MMM YYYY hh:mm", timestamp())      → "15 Jan 2024 10:30"│
  │  3.  formatdate("YYYY/MM/DD", timestamp())              → "2024/01/15"       │
  │  4.  formatdate("hh:mm:ss", timestamp())                → "10:30:00"         │
  │  5.  formatdate("MMMM DD, YYYY", timestamp())           → "January 15, 2024"  │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.9.3  timeadd(timestamp, duration)                                         │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Adds a duration to a timestamp. Duration format: "NhXmYs"     │
  │                (e.g., "24h", "1h30m", "30m", "7d").                         │
  │  Syntax:       timeadd(timestamp, duration)                                  │
  │  Parameters:   timestamp — RFC 3339 timestamp string                        │
  │                duration  — Go duration string (h, m, s, ms, us, ns)         │
  │  Return:       String — new timestamp after adding duration                 │
  │  Examples:                                                                  │
  │  1.  timeadd("2024-01-15T10:00:00Z", "24h")             → "2024-01-16T10:00:00Z"│
  │  2.  timeadd(timestamp(), "1h30m")                      → (1.5 hours later) │
  │  3.  timeadd("2024-01-15T00:00:00Z", "-1h")             → "2024-01-14T23:00:00Z"│
  │  4.  timeadd(timestamp(), "720h")                       → (30 days later)   │
  │  5.  formatdate("YYYY-MM-DD", timeadd(timestamp(), "168h")) → (1 week later)│
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.9.4  plantimestamp()                                                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Like timestamp() but STABLE during a plan — only changes on   │
  │                apply. Use this instead of timestamp() for naming resources.  │
  │  Syntax:       plantimestamp()                                               │
  │  Return:       String — stable UTC timestamp                                │
  │  Examples:                                                                  │
  │  1.  plantimestamp()                                    → "2024-01-15T10:30:00Z"│
  │  2.  "ami-${plantimestamp()}"                           → stable AMI name    │
  │  3.  replace(plantimestamp(), ":", "-")                 → file-safe timestamp│
  │  4.  formatdate("YYYYMMDD-hhmmss", plantimestamp())     → "20240115-103000"  │
  │  5.  ⚠️ plantimestamp() still changes on every apply — use data sources for  │
  │      truly stable values (e.g., data.aws_ami.latest.id)                      │
  └─────────────────────────────────────────────────────────────────────────────┘


  ╔══════════════════════════════════════════════════════════════════════════════╗
  ║  J.10 — HASH & CRYPTO FUNCTIONS (Additional)                                ║
  ╚══════════════════════════════════════════════════════════════════════════════╝

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.10.1  base64sha256(string) / base64sha512(string)                         │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Computes SHA-256/SHA-512 hash and Base64-encodes the result.  │
  │                Shorter than hex encoding — good for resource names.          │
  │  Syntax:       base64sha256(string) / base64sha512(string)                   │
  │  Return:       String — Base64-encoded hash                                  │
  │  Examples:                                                                  │
  │  1.  base64sha256("hello")                              → "LPJNul+..." (44 chars)│
  │  2.  base64sha256(file("${path.module}/main.tf"))       → (config fingerprint)│
  │  3.  base64sha512("terraform")                          → (88-char base64)   │
  │  4.  base64sha256(jsonencode(var.tags))                 → (tags hash)        │
  │  5.  substr(base64sha256(var.config), 0, 8)             → (short hash ID)    │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.10.2  sha1(string)                                                        │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Returns the SHA-1 hash (40 hex chars). Deprecated for security│
  │                — use sha256/sha512 for new projects.                         │
  │  Syntax:       sha1(string)                                                  │
  │  Return:       String — 40-character hex hash                                │
  │  Examples:                                                                  │
  │  1.  sha1("hello")                                      → "aaf4c61d..." (40) │
  │  2.  sha1(file("deprecated_config.json"))               → (legacy hash)      │
  │  3.  sha1(join("", [for f in fileset(".","*.tf") : file(f)]))                │
  │  4.  sha1("${var.project}-${var.env}")                  → (simple hash)      │
  │  5.  ⚠️ Prefer sha256 for new projects — SHA-1 is cryptographically broken   │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.10.3  rsadecrypt(ciphertext, privatekey)                                  │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Decrypts an RSA-encrypted Base64 string using a PEM private   │
  │                key. Used for decrypting Windows admin passwords from EC2.    │
  │  Syntax:       rsadecrypt(ciphertext, privatekey)                            │
  │  Parameters:   ciphertext  — Base64-encoded RSA-encrypted data              │
  │                privatekey  — PEM-formatted RSA private key                  │
  │  Return:       String — decrypted plaintext                                  │
  │  Examples:                                                                  │
  │  1.  rsadecrypt(aws_instance.win.password_data, file("~/.ssh/id_rsa"))       │
  │  2.  rsadecrypt(data.aws_kms_ciphertext.secret.ciphertext_blob, tls_private...)│
  │  3.  nonsensitive(rsadecrypt(var.encrypted_pass, file("key.pem")))           │
  │  4.  rsadecrypt(data.external.encrypted.result, var.master_key)              │
  │  5.  ⚠️ Private key must be accessible at plan time — use with caution       │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.10.4  filebase64sha256(path) / filesha256(path)                           │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Computes the hash of a FILE (not a string). Use filemd5(),    │
  │                filesha1(), filesha256(), filesha512() for hex output.        │
  │  Syntax:       filesha256(path) / filebase64sha256(path)                     │
  │  Return:       String — hash of file contents                                │
  │  Examples:                                                                  │
  │  1.  filesha256("${path.module}/script.sh")            → (64-char hex hash)  │
  │  2.  filebase64sha256("user_data.sh")                  → (44-char base64)    │
  │  3.  filemd5("lambda.zip")                             → (32-char hex, fast) │
  │  4.  filesha1("config.json")                           → (40-char hex, legacy)│
  │  5.  filebase64sha512("large_archive.tar.gz")          → (88-char base64)   │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.11.1  can(regex(...)) — SAFE Validation Pattern                           │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  The #1 validation pattern. regex() ERRORS on no match —      │
  │                wrap it in can() to convert errors to true/false.             │
  │  Standard Form:                                                              │
  │  validation {                                                                │
  │    condition     = can(regex("^PATTERN$", var.value))                        │
  │    error_message = "Value must match PATTERN."                               │
  │  }                                                                           │
  │  Examples:                                                                  │
  │  1.  can(regex("^[a-z0-9-]+$", var.bucket_name))        → (valid DNS name?)  │
  │  2.  can(regex("^\\d{1,5}$", tostring(var.port)))       → (valid port?)      │
  │  3.  can(regex("^vpc-[a-f0-9]{8,17}$", var.vpc_id))    → (valid VPC ID?)    │
  │  4.  can(regex("^ami-[a-f0-9]{8,17}$", var.ami))       → (valid AMI ID?)    │
  │  5.  can(regex("^[\\w+=/,.@-]+$", var.iam_name))       → (valid IAM name?)  │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.11.2  try() + coalesce() — Combined Safety Net                            │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Layer try() (catches errors) with coalesce() (catches null)   │
  │                for ultimate defensive coding.                                 │
  │  Pattern:      coalesce(try(VALUE, null), FALLBACK)                           │
  │  Examples:                                                                  │
  │  1.  coalesce(try(var.configs[terraform.workspace], null), var.configs.dev)   │
  │  2.  coalesce(try(tonumber(var.port), null), 80)       → (safe port number) │
  │  3.  coalesce(try(data.aws_ssm.secret.value, null), var.fallback)            │
  │  4.  coalesce(try(jsondecode(var.json_str), null), tomap({}))                │
  │  5.  coalesce(try(var.override, null), var.default)    → (override or default)│
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.11.3  for + if — Filtering & Transformation Patterns                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  The MOST common expression pattern in production Terraform.   │
  │  Syntax:       [for ITEM in LIST : RESULT]                                   │
  │                [for ITEM in LIST : RESULT if CONDITION]                      │
  │                [for KEY, VALUE in MAP : RESULT]                              │
  │  Examples:                                                                  │
  │  1.  [for s in aws_subnet.public : s.id]               → (subnet IDs)       │
  │  2.  [for s in aws_subnet.private : s.id if s.az=="a"]→ (AZ-filtered)      │
  │  3.  {for s in aws_subnet.public : s.az => s.cidr_block} → (AZ→CIDR map)   │
  │  4.  [for k,v in var.tags : "${k}=${v}"]              → (tag strings)       │
  │  5.  {for i,v in var.instances : v.name => v if v.enabled} → (enabled only)│
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.11.4  templatefile() — Dynamic Configuration Pattern                      │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  THE #1 pattern for generating cloud-init, user_data, and      │
  │                configuration files from templates.                            │
  │  Template Syntax:                                                             │
  │    ${variable}          — Insert a value                                     │
  │    %{ if CONDITION }    — Conditional block start                            │
  │    %{ else }            — Else clause                                        │
  │    %{ endif }           — Conditional block end                              │
  │    %{ for ITEM in LIST }— Loop start                                         │
  │    %{ endfor }          — Loop end                                            │
  │  Examples:                                                                  │
  │  1.  templatefile("init.sh.tpl", {env=var.env, db=aws_db.main.endpoint})     │
  │  2.  templatefile("nginx.conf.tpl", {upstream=[for i in var.backends : i]})  │
  │  3.  templatefile("policy.json.tpl", {bucket=aws_s3.assets.arn, env=var.env})│
  │  4.  base64encode(templatefile("cloud-init.yaml", {ssh_key=tls_private_key}))│
  │  5.  templatefile("env.tpl", {for k,v in var.config : k => v})               │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  J.11.5  The Splat Expression [*] — Attribute Extraction                     │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  Description:  Extracts a single attribute from ALL elements of a list.      │
  │                Modern: [*] (works with count, for_each, and lists).          │
  │                Legacy: .* (only for count resources — avoid it).             │
  │  Syntax:       RESOURCE_TYPE.NAME[*].ATTRIBUTE                               │
  │  Examples:                                                                  │
  │  1.  aws_instance.web[*].public_ip                     → ["1.2.3.4","5.6.7.8"]│
  │  2.  aws_subnet.public[*].id                           → all subnet IDs      │
  │  3.  aws_s3_bucket.assets[*].arn                       → all bucket ARNs     │
  │  4.  module.vpc[*].vpc_id                             → (NOT valid — modules)│
  │  5.  data.aws_availability_zones.available.names[*]   → ["us-east-1a","b","c"]│
  └─────────────────────────────────────────────────────────────────────────────┘
