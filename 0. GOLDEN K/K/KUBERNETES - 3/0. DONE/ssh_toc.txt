Service management
systemctl start name
Start a service
systemctl stop name
Stop a service
systemctl restart name
Restart a service
systemctl reload name
Reload service config (no restart)
systemctl status name
Show service status
systemctl enable name
Enable service at boot
systemctl disable name
Disable service at boot
systemctl is-active name
Check if service is running
systemctl is-enabled name
Check if service is enabled
systemctl mask name
Prevent service from starting

Listing units
systemctl list-units
List all active units
systemctl list-units --type=service
List active services
systemctl list-units --failed
List failed units
systemctl list-unit-files
List all installed unit files
systemctl list-dependencies name
Show unit dependencies
systemctl cat name
Show unit file contents
systemctl show name
Show all unit properties

System state
systemctl daemon-reload
Reload unit files after changes
systemctl reboot
Reboot the system
systemctl poweroff
Shut down the system
systemctl suspend
Suspend to RAM
systemctl hibernate
Hibernate to disk
systemctl get-default
Show default target (runlevel)
systemctl set-default target
Set default target
systemctl isolate rescue.target
Switch to rescue mode

Boot analysis
systemd-analyze
Show total boot time
systemd-analyze blame
List units by boot time (slowest first)
systemd-analyze critical-chain
Show critical boot path
systemd-analyze plot > boot.svg
Export boot timeline as SVG
systemctl --failed
Show failed units after boot

Unit overrides
systemctl edit name
Create drop-in override for unit
systemctl edit --full name
Edit full copy of unit file
systemctl revert name
Remove all overrides for unit
/etc/systemd/system/name.d/
Directory for drop-in overrides
systemctl --user start name
Manage user-level service
systemctl --user enable name
Enable user-level service at login

Timers
systemctl list-timers
List all active timers
systemctl list-timers --all
List all timers including inactive
OnBootSec=15min
Run 15 min after boot (timer unit)
OnCalendar=daily
Run once per day
OnCalendar=Mon *-*-* 09:00
Run every Monday at 09:00
OnCalendar=*:0/5
Run every 5 minutes
Persistent=true
Catch up missed runs after downtime
systemd-run --on-calendar="..." cmd
One-shot transient timer

Logs with journalctl
journalctl
Show all journal entries
journalctl -u name
Logs for specific service
journalctl -u name -f
Follow service logs
journalctl -u name -n 50
Last 50 lines for service
journalctl -b
Logs since last boot
journalctl -b -1
Logs from previous boot
journalctl --since "1 hour ago"
Logs from last hour
journalctl -p err
Only error-level messages
journalctl --disk-usage
Show journal disk usage
journalctl --vacuum-size=500M
Trim journal to 500MB
Writing unit files
/etc/systemd/system/
Location for custom unit files
[Unit]
Section: description and dependencies
Description=My App
Human-readable service name
After=network.target
Start after network is up
[Service]
Section: process configuration
ExecStart=/usr/bin/app
Command to start the service
Restart=always
Restart on failure
User=www-data
Run as this user
[Install]
Section: enable/disable config
WantedBy=multi-user.target
Enable in multi-user mode
