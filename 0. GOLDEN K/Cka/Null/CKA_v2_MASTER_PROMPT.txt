The original cka.html is an excellent study guide but a dead-end format:

  ❌ 72,500-line monolith — impossible to maintain
  ❌ Content baked into HTML — can't feed a database or API
  ❌ No quiz engine — questions are static text
  ❌ No progress tracking, no user accounts, no search

The RIGHT approach:

  cka.html ──extract──▶ course-data.json ──import──▶ Django DB ──API──▶ React UI
                              │
                              └── also feeds any future static HTML rebuilds

course-data.json is the single source of truth. Get this RIGHT and everything
downstream (Django models, React components, API) becomes mechanical.

  - "storage"           (PV, PVC, StorageClass, ConfigMap, Secret, hostPath)
