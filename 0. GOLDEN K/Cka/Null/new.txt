WHY A NEW VERSION?
──────────────────────────────────────────────────────────────────────────────
The original cka.html (~72,500 lines) is already excellent — dark theme, 11 parts,
40 chapters, 9 appendices, interactive sidebar, auto code detection, CKA exam
coverage. But it has limitations:

  ❌ Single monolithic file — impossible to maintain or collaborate on
  ❌ No search/filter in sidebar — finding topics is scroll-only
  ❌ No progress tracking — you lose your place every session
  ❌ No dark/light mode toggle — locked to dark theme
  ❌ No interactive quiz engine — questions are static
  ❌ CDN-dependent (Prism.js) — no offline use
  ❌ No print-friendly CSS — can't generate PDF study sheets
  ❌ No flashcard mode — no spaced-repetition learning
  ❌ No "copy command" buttons on code blocks
  ❌ No sticky progress bar showing % complete
  ❌ No keyboard shortcuts (e.g., Ctrl+K to search, Ctrl+B for sidebar)

The new version will be a MODULAR build system that GENERATES a single
self-contained HTML file, with ALL of these improvements baked in.
