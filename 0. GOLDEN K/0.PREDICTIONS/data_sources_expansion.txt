  SP2), seasons 2014-15+: FT+HT score, stats HS/AS/HST/AST/HC/AC/HF/AF/HY/AY/

the Feb–Jul 2026 transitional period is NOT in the file); (b) extra-format
files have no closing OU/AH at all — that market surface cannot come from
fdcouk for those 15 leagues.

  Bet Brain columns (Bb1X2/BbMxH/BbAvH, BbOU/BbMx>2.5/BbAv>2.5,

  CLOSING (BFEH/BFE>2.5/BFEAHH + BFEC* variants) and new books BFD (Betfred),

  matches can be backfilled from the DB (one migration) with ZERO re-downloads.
  Minor: G1/F2/B1 2017-19 use HFKC/AFKC (free kicks conceded) instead of

2a. FiveThirtyEight SPI archive — BEST free xG training-depth win.  [S/M]
    VERIFIED REALITY CHECK: the official CSVs are GONE. The GitHub folder
    soccer-spi now contains only README.md (verified via GitHub API); the real
    files lived on projects.fivethirtyeight.com, which now redirects to
    abcnews.com/politics (verified). BUT the repo license is CC-BY-4.0
    (verified via GitHub API), so pre-shutdown mirrors are legal to use with
    attribution. Verified working mirror: github.com/ilyapt/spi_matches
    (spi_matches.csv, 9.7 MB, downloaded + parsed in this survey):
      68,913 matches, 2016-07-09..2023-12-03, 40 leagues, columns: SPI ratings,
      win/draw probs, projected scores, IMPORTANCE, actual scores, shot-based
      xg1/xg2, non-shot nsxg1/nsxg2, adjusted scores.
    League overlap with US: Eredivisie, Portuguese Liga, Greek SL, Turkish SL,
    Scottish Prem, Bundesliga + 2.Bundesliga, Ligue 2, Serie B, Segunda,
    Austrian BL, Swiss SL, Norwegian, Swedish, MLS, Argentina, Brazil, China,
    Japan, Mexico, Danish + E0 benchmark (+ Belgium/Ligue 1/Serie A/La Liga if
    divisions added). Missing: Finland, Ireland, Poland, Romania.
    NEW vs what we have: per-match xG/nsxG ground truth 2016-2023 to VALIDATE/
    CALIBRATE our SOT-based xG proxies (signal-catalog 5.2+), plus a match-
    importance signal precedent. Static archive — no live use.
    Serves: training depth, proxy validation | Cost: none, keyless | License:
    CC-BY-4.0, attribute FiveThirtyEight | Effort: S import + M team-name
    mapping across 40 leagues (reuse resolve_team patterns; one-time).

2b. Understat — richest free shot-minute data, but ToS-hostile.  [M, gray]
    Coverage (verified live): 6 leagues — EPL, La Liga, Bundesliga, Serie A,
    Ligue 1, RFPL(Russia) — since 2014/15. Per-shot JSON embedded in match
    pages (minute, xG, player, situation, shot type) — exactly what minute-
    interval goal markets need. HONESTY: https://understat.com/robots.txt is
    "User-agent: * / Disallow: /" (verified) — scraping is explicitly
    disallowed; there is no official API; community scrapers exist but a
    production pipeline on it is a policy violation with breakage risk.
    Overlap with our leagues: only D1 (+E0 benchmark; +I1/SP1/F1 if added).
    RECOMMENDATION: do NOT build production dependency; at most one-off local
    research to sanity-check minute-distribution priors.
    Serves: minute markets (research only) | Cost: none | License: disallowed
    by robots.txt | Effort: M + reputational/breakage risk.

2c. StatsBomb open-data (GitHub) — free event data for PROTOTYPING.  [S]
    Verified competitions.json: full 2015/16 season for all Big-5 leagues,
    Bundesliga 2023/24, Ligue 1 2021-23, PL 2003/04+2015/16, La Liga 2004-2020
    (Barcelona-centric), MLS 2023, plus WCs/Euros/Copa/AFCON, women's leagues.
    Event-level JSON with minute+second, shot xG, freeze-frames, lineups.
    NEW vs what we have: true event timelines to DESIGN and unit-test the
    minute-interval market models (goal-time hazard curves, 1st-10-min rates)
    before any paid live source is bought. NOT a production source for our
    leagues (wrong/old seasons).
    License (verified README): free with attribution "state the data source as
    StatsBomb and use our logo"; registration not required for the GitHub data.
    Serves: minute-market model design, training methodology | Cost: none,
    keyless | Effort: S (well-documented JSON; parsers exist).
    URL: https://github.com/statsbomb/open-data

2d. FBref (Sports Reference) — per-shot tables w/ minutes for Big-5.  [M]
    Big-5 match pages carry Opta shot tables (minute, xG, PSxG) from 2017-18.
    Scraping policy (verified via their bot-traffic page/search): hard cap
    ~10 requests/minute, violators blocked up to 24h; polite scraping below
    the cap is de facto tolerated (worldfootballR/soccerdata communities run
    on it). Underlying data is Opta-licensed — do not republish raw.
    Only useful if we add I1/SP1/F1 (and for E0/D1). Slow full-history pulls
    (rate cap) — days of polite crawling.
    Serves: minute markets + xG for Big-5 | Cost: none, keyless | License:
    site ToS + Opta restrictions; internal use tolerated, republishing not |
    Effort: M (existing libs help; rate-cap management mandatory).

3. FREE FIXTURES / RESULTS APIs (7-day trial coverage)
--------------------------------------------------------------------------------
3a. ESPN hidden JSON API — the strongest free+keyless fixtures/events feed.
    Verified live (site.api.espn.com/apis/site/v2/sports/soccer/{code}/
    scoreboard?dates=YYYYMMDD): works keyless for eng.1, ned.1, nor.1, por.1,
    tur.1 (gre.1 returned 0 events on the date tried — verify per league).
    Each event carries status, competitors, ODDS object, and a `details` array
    of scoring plays/cards WITH clock ("8'", value seconds) and players
    (verified on 2026-05-10 EPL). Season calendar included -> can enumerate
    fixtures ~any horizon, filling fdcouk's between-rounds fixture gaps
    (ADR 014 lists this exact weakness).
    HONESTY: undocumented, unofficial, no SLA, ToS-gray, can change silently.
    Use as SECONDARY/fallback fixture+goal-minute source, never the spine, and
    never redistribute.
    Serves: trial coverage (fixture discovery beyond ~1 week), minute markets
    (goal minutes for most of our leagues incl. extra ones: nor.1 verified;
    arg/bra/jpn/mex/chn codes exist), postponement detection | Cost: none,
    keyless | Effort: M (league-code map + team-name resolution + fragility
    guards).

3b. OpenLigaDB — keyless community API, Germany only.  [S/M]
    Verified live: api.openligadb.de/getmatchdata/bl1/2024/1 returns HT+FT
    results AND goals[] with matchMinute, scorer, penalty/own-goal flags.
    Covers Bundesliga 1/2/3 + DFB-Pokal, seasons back ~2003.
    NEW: free goal minutes for D1+D2 — the ONLY clean, keyless, ToS-clean
    minute source for any of our current leagues. Enables first D1/D2
    minute-interval market models (better market.txt lines "Total Goals O/U
    from 1 to N minute", "10 minutes 1X2").
    HONESTY: community-maintained, no SLA; verify against fdcouk results (we
    already have FT/HT to cross-check).
    Serves: minute markets (2 leagues), goal-minute training depth | Cost:
    none, keyless | Effort: S/M.

3c. football-data.org free tier — SKIP.
    Verified pricing page: free = 12 competitions (CL, PL, Championship, BL1,
    SA, PD, FL1, DED, PPL, Brazil Serie A, WC, EC), 10 calls/min, requires a
    free API KEY, scores/schedules DELAYED, and it explicitly EXCLUDES goal
    scorers, lineups, stats, odds. Adds nothing over fdcouk fixtures.csv
    (which even has odds) except Brazil fixtures redundancy. Not keyless.

3d. TheSportsDB — LOW VALUE.
    Free community JSON API (shared test key; $9/mo Patreon for a real key +
    V2). Crowd-sourced data, no minute-event guarantees, moderate reliability.
    Useful only for logos/artwork if the frontend ever wants them.

4. ODDS DEPTH
--------------------------------------------------------------------------------
4a. Betfair Historic Data, BASIC tier — the only truly free TIMESTAMPED
    odds archive.  [L]
    From the Betfair developer docs/community (historicdata.betfair.com is an
    SPA; verified via support articles + betfair-datascientists guide): BASIC
    tier is free, covers exchange markets from ~April 2015, pre-off data at
    1-MINUTE granularity, last-traded price only (no volume, no ladder).
    Requires a (free) Betfair account to download; TAR of bz2 JSON market
    streams; heavy processing.
    NEW vs what we have: genuine timestamped pre-match odds SERIES (our
    OddsSnapshot currently gets one capture/day from fixtures.csv) -> line-
    velocity features, CLV research, and — uniquely — CORNERS and other
    side-market odds history where such exchange markets existed. This is the
    only free path to historical odds for the corners/team-totals surface.
    HONESTY: UK/geo restrictions on Betfair accounts may apply; data files are
    large; a meaningful subset (one league-season pilot) is the right first
    bite. | Cost: free w/ account (not keyless) | Effort: L.
    URLs: https://historicdata.betfair.com/,
    https://betfair-datascientists.github.io/data/usingHistoricDataSite/,
    https://support.developer.betfair.com/hc/en-us/articles/360002407732

4b. OddsPortal — NOT RECOMMENDED.
    Reality check (2026 guides): odds tables are JS-rendered (headless browser
    required), light Cloudflare/rate-limiting, community scrapers exist
    (OddsHarvester etc.), ToS prohibits scraping. Historical opening+closing
    odds exist for huge league coverage — tempting for the 15 extra leagues'
    OU/AH gap — but it's a fragile, ToS-violating pipeline with no timestamps
    beyond open/close. Only revisit if the extra-league OU/AH gap becomes a
    hard blocker and no paid option is on the table.

4c. Already-free closing-line notes: fdcouk main files carry Pinnacle closing
    (PSC*) since 2012-13 and Betfair Exchange closing (BFEC*) since 2025-26 —
    post-match only (backfilled in result files). ACTION 1 captures these.
    The extra files' closing 1X2 (PSCH/MaxC/AvgC/BFEC/B365C) is already
    parsed. aussportsbetting.com historical Excel sheets exist for EPL etc.
    (open+close, totals) — NOT verified live in this survey; low priority.

5. CLUB ELO (api.clubelo.com) — free keyless Elo + score distributions  [S]
--------------------------------------------------------------------------------
    Verified live (intermittently): /Fixtures returned CSV with, per upcoming
    match: full goal-difference probability distribution AND exact-score
    probabilities R:0-0..R:6-0 — i.e., a free external CORRECT-SCORE benchmark
    that maps directly onto our goal-range / team-total / O-U market surface.
    Other endpoints: /{YYYY-MM-DD} daily ranking, /{ClubName} full Elo history
    (Europe-wide, decades deep). No key, plain CSV.
    HONESTY: the API was FLAKY during this survey — /Fixtures succeeded once,
    the ranking/history endpoints returned empty responses on several tries
    (site had a known outage Apr 2025; API doc page last updated Feb 2026).
    Europe only — no MLS/BRA/ARG/JPN/CHN/MEX. Treat as a nightly best-effort
    pull with graceful skip (matches ADR 007 no-crash pattern).
    NEW vs what we have: independent Elo (validates our own), and an external
    correct-score prior to benchmark DC calibration per league.
    Serves: training depth (benchmark), calibration QA | Cost: none, keyless |
    License: free API, credit clubelo.com | Effort: S.

WHAT REMAINS IMPOSSIBLE WITHOUT PAID / KEYED SOURCES
================================================================================
- Lineups, injuries, suspensions, transfers (signal families 5.4/5.8; gate 8
  confirmed-XI): API-Football key or similar. No free substitute found.
- Live / intraday odds polling, T-24h + final-2h closing-line capture, CLV on
  OUR bets going forward: The Odds API / bookmaker APIs. fdcouk gives one
  snapshot/day pre-match + closing only after the match.
- Pinnacle as a LIVE pre-match anchor: fdcouk still publishes PS/PSC in
  2025-26 result files (verified), but only retrospectively; a live sharp
  anchor post-Jan-2026 needs a keyed odds feed. Free partial mitigation:
  Betfair Exchange closing (BFEC*, Action 1) + Betfair Historic research.
- Odds history for the exotic surface (corners lines, team totals, first-half
  lines, minute markets) across our leagues: no free archive exists except
  Betfair Historic BASIC (exchange markets, L effort). Modeling is possible
  from stats; PRICING/edge-measurement vs the book is the missing half.
- Referee ASSIGNMENTS pre-match (we only get names post-match, England/
  Scotland), stadium/weather, granular player events for all 27+ leagues.
