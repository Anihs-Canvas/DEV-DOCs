Soccer Prediction Model - Historical Feature Engineering Guide

IMPORTANT RULE Use only information available before kickoff. Never use
post-match statistics, live odds, or any information from the match
being predicted.

Suggested Pipeline Historical Fixtures ↓ Rolling Feature Generator ↓ ELO
Rating Updater ↓ Injury & Availability Encoder ↓ Feature Store
(PostgreSQL/Parquet) ↓ XGBoost Classifier ↓ Probability Calibration ↓
Predictions

Recommendation Start with approximately 40 engineered features and
XGBoost. Add TensorFlow later for sequence models, player embeddings, or
advanced deep learning.




Team-level performance features

Rolling form: points per game, goals for/against over last 3/5/10 matches (weighted more heavily toward recent games)
xG-style metrics: if the API doesn't give xG directly, approximate from Statistics (shots, shots on target, shot location if available) — xG for/against, xG difference, xG overperformance (finishing efficiency) per team
Home/away split form — teams often have very different home vs away profiles
Rest days / fixture congestion — days since last match, matches in last 14 days (fatigue proxy), especially relevant with European competition schedules
Travel distance — for away teams, especially in continental competitions
Strength of schedule — average quality of recent opponents (weight by opponent's league position or rating)

Head-to-head & context features

H2H history — not just win/loss, but goal patterns, margin trends between the two specific teams
League position / points gap at time of match (not final table — this is a common leakage mistake)
Match importance — relegation battle, title race, dead rubber, cup knockout vs group stage

Squad/personnel features

Squad availability — from Injuries + Sidelined, compute a "% of first-choice XI available" or weighted absence score (weight by player importance/minutes played)
Key player minutes/form — top scorer's recent goal involvement, whether star players are rested/rotated
Lineup strength — once Line-ups are published pre-match, compare average player rating/market value vs season average XI (careful: this data often arrives too close to kickoff for pre-match betting use cases)
Manager tenure/changes — new manager bounce effect, days since managerial change (from Coachs data)
Transfer activity — recent squad churn (new signings bedding in, key departures)

Market/odds-derived features

Implied probability from Pre-match Odds — often your strongest baseline feature; odds movement (opening vs closing line) captures market information you can't otherwise engineer
Odds from multiple bookmakers — consensus vs outlier lines, over/under and BTTS odds as auxiliary signals

External data not in this API (worth sourcing separately)

Weather — temperature, rain, wind for outdoor stadiums (affects playing style/scoring)
Referee tendencies — cards/penalties per game, home bias (some APIs include referee in fixture data — check if yours does)
Pitch/stadium factors — altitude (big in South America), pitch dimensions
Crowd/attendance — capacity % filled as a home-advantage proxy

Modeling considerations

Watch for temporal leakage — always compute rolling/form features using only data available before kickoff
Consider target formulation: 1X2 classification vs goals regression (Poisson/Dixon-Coles) vs BTTS/Over-Under binary — each benefits from different feature emphasis
League-specific calibration — a "strong form" signal means different things in the Premier League vs a lower-tier league; consider normalizing form metrics within-league
