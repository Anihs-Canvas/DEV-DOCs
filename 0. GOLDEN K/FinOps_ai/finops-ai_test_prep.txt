🎯 WHAT IS anihpj/jobpost (AI Edition)?
   anihpj is a Django-based job board enhanced with AI/ML capabilities:
   • AI Job Matching Engine: BERT-based NLP model that matches candidates to jobs
   • AI Salary Predictor: Regression model predicting market salary ranges
   • AI Resume Parser: OCR + NLP pipeline extracting structured data from PDFs
   • AI Interview Scheduler: Optimization algorithm for multi-party scheduling
   • PostgreSQL with pgvector: Vector embeddings for semantic job search
   • Redis: Caching AI predictions, Celery task queues for async ML jobs
   • GPU Worker Nodes: NVIDIA A10G GPUs for model training and inference

Before diving into the exam domains, this section builds your FinOps
mental model. Essential for novices; useful refresher for everyone.

F.1 What Is FinOps & Why Does AI Need It?
    • The FinOps Framework — Inform → Optimize → Operate lifecycle
    • Why AI is different: GPU costs 50-100× more than CPU, training is spikey,
      inference is continuous but unpredictable, data egress is a hidden cost
    • The "AI Bill Shock" problem — real case studies:
      - Startup burns $72K in 3 days on unmonitored GPU training
      - Enterprise ML team discovers $500K annual waste from idle GPU instances
      - Team trains on on-demand when reserved would save 40%
    • The 6 FinOps Domains applied to AI workloads
    • The Shared Responsibility Model for AI costs:
      Cloud Provider: meter accurately, provide cost data, offer discounts
      FinOps Team: allocate, budget, forecast, report, optimize
      ML Engineers: right-size GPUs, use spot, batch efficiently, track experiments
    • Why anihpj/jobpost is your AI FinOps sandbox
    🟢 Novice

F.2 FinOps Terminology — The Lexicon You MUST Know
    • Core Terms: CapEx vs OpEx, TCO (Total Cost of Ownership), ROI, Unit Economics
    • Cost Types: On-Demand, Reserved Instances (RI), Savings Plans, Spot/Preemptible
    • GPU-Specific: GPU-hour, CUDA cores, VRAM, tensor cores, FP16 vs FP32,
      GPU memory bandwidth, NVLink, MIG (Multi-Instance GPU)
    • AI Cost Concepts: Training cost, Inference cost, Cold start latency,
      Batch vs Real-time inference, Model serving cost, Embedding storage cost
    • Cloud Pricing: Compute (EC2/GCE), Storage (S3/EBS/EFS), Data Transfer,
      API Gateway, Load Balancer, NAT Gateway (hidden $32/month!)
    • AWS-Specific: EC2 GPU instances (g5, p4d, p5), S3 Intelligent-Tiering,
      AWS Budgets, Cost Explorer, Compute Optimizer, Trusted Advisor
    • Allocation: Cost Categories, Tags (cost-center, team, env, workload),
      CUR (Cost & Usage Report), Amortized vs Unblended costs
    • KPIs: Cost-per-prediction, GPU utilization %, Spot interruption rate,
      Training cost per epoch, Inference latency vs cost tradeoff
    🟢 Novice

F.3 The AI Cost Lifecycle — Where Money Flows
    • Phase 1 — Data: Ingestion, storage, preprocessing, labeling costs
    • Phase 2 — Training: GPU-hours per epoch, hyperparameter tuning multiplier,
      experiment tracking cost, checkpoint storage
    • Phase 3 — Deployment: Model registry storage, container image storage,
      inference endpoint compute, auto-scaling overhead
    • Phase 4 — Inference: Per-request cost, batch vs real-time tradeoff,
      cold start cost, model caching strategies
    • Phase 5 — Monitoring: Log storage, metrics pipeline, alerting infra,
      dashboard hosting, data retention costs
    • The "Hidden Costs": Data transfer between regions, NAT Gateway hourly,
      idle GPU detection lag, orphaned EBS volumes, old model artifacts in S3
    🟢 Novice | 🟡 Intermediate: Cost waterfall diagrams

F.4 anihpj/jobpost AI Edition — The Application Under Financial Analysis
    • Full architecture with cost annotations at every layer
    • Django web tier: $0.04/hr (CPU-only, cheap)
    • Django API tier: $0.08/hr/replica × 2-10 replicas (HPA)
