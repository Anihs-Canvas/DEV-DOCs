GETTING STARTED
This section contains the essential commands for logging into ArgoCD, managing
contexts, and checking the CLI version. These are the first commands every user
runs when working with ArgoCD.

argocd login
Log in to an ArgoCD server. This authenticates the CLI and stores a token
for subsequent commands. Supports SSO, local accounts, and token-based auth.

Usage
  argocd login SERVER [flags]

Examples
  # Login to ArgoCD with SSO
  argocd login argocd.anihpj.com --sso

  # Login with username and password
  argocd login argocd.anihpj.com --username admin --password mypassword

  # Login and skip TLS verification (development only)
  argocd login argocd.anihpj.com --insecure

  # Login with a specific port
  argocd login localhost:8080

  # Login using an auth token
  argocd login argocd.anihpj.com --auth-token eyJhbGciOi...

Flags
  --auth-token string        Authentication token
  --cert-file string         Certificate file for TLS
  --client-certificate string Client certificate file
  --client-crt string        Client certificate file
  --client-crt-key string    Client certificate key file
  --grpc-web                 Use gRPC-web protocol
  --grpc-web-root-path string Root path for gRPC-web
  -h, --help                 Help for login
  --insecure                 Skip TLS certificate verification
  --name string              Name for the context
  --password string          Password for authentication
  --port int                 Port number
  --skip-test-tls            Skip testing TLS
  --sso                      Login via SSO
  --username string          Username for authentication

argocd logout
Log out from the current ArgoCD server context. Removes stored credentials.

Usage
  argocd logout [CONTEXT] [flags]

Examples
  # Logout from current context
  argocd logout

  # Logout from a specific context
  argocd logout anihpj-prod

Flags
  -h, --help   Help for logout

argocd context
Manage ArgoCD connection contexts. Switch between multiple ArgoCD servers.

Usage
  argocd context [CONTEXT] [flags]

Examples
  # List all contexts
  argocd context

  # Switch to a specific context
  argocd context anihpj-prod

  # Delete a context
  argocd context --delete anihpj-staging

Flags
  --delete           Delete the specified context
  -h, --help         Help for context

argocd version
Print the version information of the ArgoCD CLI and server.

Usage
  argocd version [flags]

Examples
  # Print CLI version
  argocd version

  # Print client and server version
  argocd version --short

Flags
  --client           Show client version only
  -h, --help         Help for version
  -o, --output string Output format (json, yaml, wide)
  --server string    Server address
  --short            Print version in short format

APP MANAGEMENT
Commands for managing ArgoCD Applications. These are the core day-to-day commands
for deploying, syncing, and troubleshooting applications.

argocd app create
Create a new Application in ArgoCD. An Application defines the source repository,
target cluster, sync policy, and desired state.

Usage
  argocd app create APPNAME [flags]

Examples
  # Create an app from a git repository
  argocd app create jobpost-api \
    --repo https://github.com/anihpj/jobpost.git \
    --path k8s/anihpj \
    --dest-server https://kubernetes.default.svc \
    --dest-namespace anihpj

  # Create an app with Helm chart
  argocd app create jobpost-api \
    --repo https://github.com/anihpj/jobpost.git \
    --helm-chart jobpost \
    --dest-server https://kubernetes.default.svc \
    --dest-namespace anihpj

  # Create with automated sync policy
  argocd app create jobpost-api \
    --repo https://github.com/anihpj/jobpost.git \
    --path k8s/anihpj \
    --dest-server https://kubernetes.default.svc \
    --dest-namespace anihpj \
    --sync-policy automated \
    --auto-prune

  # Create with labels and annotations
  argocd app create jobpost-api \
    --repo https://github.com/anihpj/jobpost.git \
    --path k8s/anihpj \
    --dest-server https://kubernetes.default.svc \
    --dest-namespace anihpj \
    --label team=backend \
    --annotation environment=production

  # Create app targeting a specific revision
  argocd app create jobpost-api \
    --repo https://github.com/anihpj/jobpost.git \
    --path k8s/anihpj \
    --dest-server https://kubernetes.default.svc \
    --dest-namespace anihpj \
    --revision v2.1.0

Flags
  --allow-empty                    Allow empty application
  --annotation stringArray         Set annotation
  --auto-prune                     Enable automatic pruning
  --config-management-plugin string Config management plugin name
  --dest-name string               Destination cluster name
  --dest-namespace string          Destination namespace
  --dest-server string             Destination cluster URL
  --directory-exclude string       Exclude directories
  --directory-include string       Include directories
  --directory-recurse              Recurse directories
  -f, --file string                File containing app definition
  --helm-chart string              Helm chart name
  --helm-set stringArray           Helm set values
  --helm-set-file stringArray      Helm set file values
  --helm-set-string stringArray    Helm set string values
  -h, --help                       Help for create
  --jsonnet-ext-var-str stringArray Jsonnet ext var
  --jsonnet-tla-str stringArray    Jsonnet top level arg
  -l, --label stringArray          Set label
  --name string                    Application name
  --nameprefix string              Name prefix
  --namesuffix string              Name suffix
  --parameter stringArray          Set parameter overrides
  --path string                    Path in repository
  --plugin-env stringArray         Plugin env variables
  --project string                 Application project (default "default")
  --release-name string            Helm release name
  --repo string                    Repository URL
  --repos string                   Repositories
  --retry-backoff-duration duration Retry backoff base duration
  --retry-backoff-factor int       Retry backoff factor
  --retry-backoff-max-duration duration Retry backoff max duration
  --retry-limit int                Retry limit
  --revision string                Revision (branch, tag, commit)
  --revision-history-limit int     Revision history limit
  --self-heal                      Enable self-heal
  --sync-option stringArray        Sync options
  --sync-policy string             Sync policy (none, automated)
  --sync-retry-limit int           Sync retry limit
  --validate                       Validate application spec
  --values stringArray             Helm values file
  --values-literal-file string     Helm values literal file

argocd app sync
Synchronize an Application to its target state. Compares the live cluster
state with the desired state in Git and applies changes.

Usage
  argocd app sync APPNAME [flags]

Examples
  # Sync an application
  argocd app sync jobpost-api

  # Sync with specific resources only
  argocd app sync jobpost-api --resource apps:Deployment:jobpost-api

  # Sync with prune (delete resources not in Git)
  argocd app sync jobpost-api --prune

  # Sync with force (recreate resources)
  argocd app sync jobpost-api --force

  # Sync and wait for healthy
  argocd app sync jobpost-api --async=false

  # Dry-run sync (preview changes)
  argocd app sync jobpost-api --dry-run

Flags
  --async                        Sync asynchronously
  --dry-run                      Preview changes without applying
  --force                        Force apply (delete and recreate)
  -h, --help                     Help for sync
  --local string                 Path to local manifests
  --local-repo-root string       Local repo root
  --prune                        Delete resources not in Git
  --resource stringArray         Sync specific resources
  --retry-backoff-duration duration Retry backoff base
  --retry-backoff-factor int     Retry backoff factor
  --retry-backoff-max-duration duration Retry backoff max
  --retry-limit int              Number of sync retries
  --revision string              Sync to specific revision
  --server-side                  Use server-side apply
  --strategy string              Sync strategy (apply, hook)
  --timeout uint                 Timeout in seconds

Commands for managing ArgoCD Projects. Projects provide logical groupings of

argocd proj create
Create a new ArgoCD Project.

Usage
  argocd proj create PROJECT [flags]

Examples
  # Create a basic project
  argocd proj create anihpj --dest https://kubernetes.default.svc,anihpj

  # Create with source repo restriction
  argocd proj create anihpj \
    --dest https://kubernetes.default.svc,anihpj \
    --src https://github.com/anihpj/jobpost.git

  argocd proj create anihpj \
    --dest https://kubernetes.default.svc,anihpj \
    --description "Anihpj project - JobPost application"

    --dest https://kubernetes.default.svc,anihpj \
    --allow-cluster-resource "*/Deployment"

These flags are available on ALL argocd commands and control CLI behavior.

Global Flags
      --argocd-context string           The name of the Argo-CD server context to use
      --auth-token string               Authentication token; or set ARGOCD_AUTH_TOKEN env var
      --client-crt string               Client certificate file
      --client-crt-key string           Client certificate key file
      --config string                   Path to Argo CD config (default "~/.config/argocd/config")
      --controller-name string          Name of the Application controller (default "argocd-application-controller")
      --core                            Talk directly to Kubernetes instead of Argo CD API server
      --grpc-web                        Enable gRPC-web protocol (for proxies without HTTP2)
      --grpc-web-root-path string       gRPC-web root path
  -H, --header strings                  Additional headers for all requests
      --http-retry-max int              Max retries for HTTP connection (default varies)
      --insecure                        Skip server certificate and domain verification
      --kube-context string             Directs command to specific kube-context
      --logformat string                Log format: json or text (default "json")
      --loglevel string                 Log level: debug, info, warn, error (default "info")
      --plaintext                       Disable TLS
      --port-forward                    Connect via port forwarding to argocd-server
      --port-forward-namespace string   Namespace for port forwarding
      --prompts-enabled                 Enable/disable interactive prompts
      --redis-compress string           Redis compression: gzip or none (default "gzip")
      --redis-haproxy-name string       Redis HA Proxy name (default "argocd-redis-ha-haproxy")

      --server-crt string               Server certificate file
      --server-name string              API server name (default "argocd-server")
